# Dataset licenses and attribution

The repository's MIT license covers original RiverQualityAtlas application code only. The bundled MapLibre worker has a separate BSD-3-Clause license; its complete upstream notice is in [licenses/MapLibreGL.txt](../licenses/MapLibreGL.txt). The official v1.1 data license archive (`Caravan-Qual_licenses.zip`) contains a summary README and 35 source-specific notes. The README states that the Caravan-Qual data release is licensed CC BY 4.0 and identifies distinct terms for streamflow, water-quality, GEOGLOWS/TDX-Hydro and ERA5-Land sources.

The same archive records source-specific qualifications, including CAMELS-CZ under CC BY-NC 4.0, LamaH-CE under CC BY-SA 4.0, GRDC national-owner terms, permission requirements for redistribution of the Wilkinson pharmaceutical data, and heterogeneous EMPODAT licensing. Attribute Caravan-Qual under its stated release license. Before extracting or redistributing a subset, review its source note and retain its attribution and conditions with exported data.

Dataset citation: Jones et al., “Caravan-Qual: A global scale integration of water quality observations into a large-sample hydrology dataset,” [Scientific Data](https://doi.org/10.1038/s41597-026-07352-7). Data release: Caravan-Qual lite v1.1, [10.5281/zenodo.21337532](https://doi.org/10.5281/zenodo.21337532). Source repository: [SustainableWaterSystems/Caravan-Qual](https://github.com/SustainableWaterSystems/Caravan-Qual), which identifies BSD-3-Clause for its code. The code license and data licenses are distinct.

Map tiles in local development come from OpenStreetMap and are attributed in the map. Public deployment must use a tile service under appropriate terms and retain attribution.
